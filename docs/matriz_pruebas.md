- **Versión probada:** `1.0.0+1` (rama `g62-7-itinerario-colaborativo-presupuesto`, commit `f84c8ae`).
- **Fecha de ejecución:** 08/11/2026.
- **Resumen:** 23 casos. **14 ejecutados**: 13 aprobados a la primera y 1 (QA-23) que falló, se corrigió (DEF-10) y se aprobó en la segunda ejecución. **9 pendientes**, porque necesitan un dispositivo Android con Firebase y cuentas reales.

**Estado:** *Aprobado* = el resultado obtenido coincide con el esperado. *Fallido* = no coincide (se registra el defecto). *Pendiente* = aún no se ejecuta; no se marca como aprobado.

## Limitaciones conocidas de esta ejecución

- Los casos **D** necesitan Android SDK, Firebase con las reglas publicadas y las cuentas de los tres roles. Al ejecutarlos, llenar "Resultado obtenido", "Estado" y "Evidencia" en esta tabla.
- En la ejecución **W**, las pantallas internas usan los datos de prueba sin Firebase, así que no prueban la sincronización ni las transacciones reales. Eso lo cubren QA-12, QA-15, QA-16 y QA-22.
- La versión web no es el objetivo de la entrega (es Android). En el navegador integrado del equipo de pruebas, Drift web no pudo abrir su *worker*, así que para la ejecución W se usó una base en memoria.
